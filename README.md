### <img src="https://api.iconify.design/lucide:folder-git-2.svg?color=%232952FF" width="18" height="18" valign="middle" /> Selected Work

#### <img src="https://api.iconify.design/lucide:trophy.svg?color=%23FF6B4A" width="16" height="16" valign="middle" /> [CampusTrace](https://franklinbugauisan.sanx.dev/) — University Lost & Found Platform *(2025–2026)*
* **Problem:** Fragmented lost-and-found reporting across university campuses makes item recovery slow and uncoordinated.
* **System:** Multi-tenant web and mobile platform combining AI image recognition, semantic matching, and RAG-assisted search to connect lost and found items.
* **Outcome:** 1st Place / Champion, Most Innovative Project — 16th ICT Roadshow.
* **Stack:** `React` · `React Native` · `FastAPI` · `RAG` · `AI Image Matching`

#### <img src="https://api.iconify.design/lucide:sparkles.svg?color=%232952FF" width="16" height="16" valign="middle" /> Remie — AI-Powered Personal Productivity Assistant *(2026)*
* **Problem:** Tasks, reminders, expenses, and calendars usually live in separate apps, breaking a person's workflow.
* **System:** An assistant that combines task management, reminders, expense tracking, calendar planning, and natural-language personal memory, with offline-first sync and AI-assisted recall.

#### <img src="https://api.iconify.design/lucide:book-open.svg?color=%232952FF" width="16" height="16" valign="middle" /> [Learni](https://franklinbugauisan.sanx.dev/) — AI-Powered Learning Platform *(2025–2026)*
* **Problem:** Self-directed learners struggle to turn open-ended topics into a structured, measurable study path.
* **System:** Web and mobile platform that generates personalized roadmaps, quizzes, and progress analytics.
* **Stack:** `Next.js` · `React Native` · `Analytics` · `AI APIs`

#### <img src="https://api.iconify.design/lucide:search.svg?color=%232952FF" width="16" height="16" valign="middle" /> [Portfolio RAG Chatbot](https://franklinbugauisan.sanx.dev/) — Grounded AI Retrieval *(2025)*
* **Problem:** A static portfolio takes manual digging to verify specific architecture choices, skills, and project decisions.
* **System:** RAG chatbot using vector-based semantic search with intent detection, response caching, and cost-optimized retrieval to answer questions about experience and projects.
* **Stack:** `Python` · `LangChain` · `Vector Search` · `Semantic Retrieval`

#### <img src="https://api.iconify.design/lucide:wallet.svg?color=%232952FF" width="16" height="16" valign="middle" /> [perakoPH](https://franklinbugauisan.sanx.dev/) — Financial Progressive Web App *(2026)*
* **Problem:** Personal finance apps tend to break down offline, leaving unsynced entries and conflicting balances across devices.
* **System:** PWA with local-first storage, conflict detection, cloud persistence, retry handling, and AI-assisted transaction entry.
* **Stack:** `PWA` · `Cloud Persistence` · `Conflict Detection` · `Offline Sync`
